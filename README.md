his course emphasizes component-based software development using C# .NET.  You will be introduced to software development techniques applicable in a component (class)-based, integrated software development environment (IDE).  You will learn (and practice using) the C# .NET language, object-oriented software design techniques, and the principles of good user interface design.  You will also learn how to navigate and take full advantage of an IDE in building quality software, including user interfaces to databases, sequential files, and graphics tools.  Object-oriented concepts such as inheritance, polymorphism, static and dynamic binding, and abstract class components will be covered.  The primary focus is on windows-based software products.
